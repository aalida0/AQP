# Grid automation

`event_generation/`: PanDA tasks consuming a gridpack with the
**same full JO** used to create it on AF/Condor; validation of
PDF/scale reweighting and FxFx Pythia showering.

`submit/`: general submission scripts and task bookkeeping.
`download/`: collect Grid log.generate archives, event datasets,
and performance metadata.

All three directories are workflow scaffolds; no working
PanDA submission automation is claimed yet.
