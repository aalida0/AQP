# Z+jets samples

Use `ZEE/<configuration>/<DSID>/` for Condor/gridpack JobOptions and
`ZEE/event_generation/grid_submit_<configuration>/<DSID>/` for the matching
ATLAS Grid event-generation JobOptions. Each JO directory contains its
own auxiliary Fortran sources and patch files, when required.

Configurations to add after validation: standard111, delta111,
delta221, delta441.
