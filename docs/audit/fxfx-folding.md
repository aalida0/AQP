# FxFx matching and folding

**Confirmed source configuration.** The recovered process has 0/1/2-jet NLO QCD multiplicities ([E05](evidence.md#e05):49–51). Its card sets FxFx `ickkw=3`, generation threshold `ptj=8`, jet algorithm/radius 1, and unfixed scales with dynamical choice −1 ([E04](evidence.md#e04):24–40). Installed validation enforces these FxFx scale/jet choices ([MG01](evidence.md#mg01):5454–5476).

Original and pilot EVNT JOs request `nJetMax=2`, `qCut=20` ([E01](evidence.md#e01):148–151; [E02](evidence.md#e02):174–176; [E03](evidence.md#e03):33–35). The installed release include translates these to FxFx controls and supplies `qCutME=8`, `nQmatch=5` ([PY01](evidence.md#py01):24–45). Thus no multiplicity/threshold mismatch was demonstrated by this inspection. Generation and shower thresholds are distinct controls.

**High-priority runtime gap.** Source establishes the available include's translation, conditional on resolving that include. The wrapper checks a hook-added message and processed count, without verifying a final settings dump ([E16](evidence.md#e16):107–120). Future validation must record resolved include identities, effective FxFx controls, input LHE identity, hook list and signed matched normalization. TXT mode intentionally omits the LHE/FxFx includes; its dummy event is not a shower validation ([E02](evidence.md#e02):166–176).

**Confirmed duplicate-key ambiguity.** The recovered card has an earlier false `MCatNLO_DELTA` and later true `mcatnlo_delta` ([E04](evidence.md#e04):23,65). The installed parser lowercases names and applies assignments in file order; later user assignments can replace earlier ones ([MG01](evidence.md#mg01):1517–1529,2778–2790). Effective Delta is **true**. Flag the duplicate as configuration hygiene and parser-test coverage, not a disabled-Delta defect.

**Keep the dimensions separate.** FxFx, Delta and folding are separate controls: the installed runtime writes matching, Delta and generation-cut controls separately ([MG02](evidence.md#mg02):4669–4674). Supported folding entries are checked independently ([MG01](evidence.md#mg01):5580–5588). A Delta/folding label does not establish effective shower matching.

**High-priority recovery gap.** Reconstruction combines genuine `res_1.dat` fields with supplied controller metadata ([E11](evidence.md#e11):129–149), checks grid-file presence/labels (:116–124), and hashes result files (:153). The original reconstruction helper omits `fold_string`; its baseline repository counterpart already supplies it at line 138 (see [E11](evidence.md#e11)). This is a historical source difference, not a new missing-key defect in the baseline repository. The separate repair supplies the missing folding string after channel/stage/path checks ([E12](evidence.md#e12):71–98,115–116). Native generation-only restart reloads the checkpoint and stage-1 results, skipping MINT0/1 ([MG02](evidence.md#mg02):1992–2002,2125–2131). A successful restart therefore does not independently validate the integration provenance. Require native-checkpoint parity and joint hashes of grids, cards, sources and executables; no recovery-induced physics bias has been demonstrated.

**Proposed, unperformed physics tests:** weighted differential jet-resolution and inclusive/exclusive jet-rate checks across the merging region; matching-scale variations distinct from renormalization/factorization variations; independent-seed folding comparisons with otherwise identical inputs. Exact jet definitions, admissible variations and statistical acceptance criteria must be specified before running these tests; no universal numerical tolerance is established here.
