# Condor reliability

**Existing outcomes.** The older eight-core LHE node exited nonzero after an `open_count_CLOSE` unbound-variable error ([E22](evidence.md#e22):2; [E23](evidence.md#e23):41–42). The later sixteen-core LHE and shower nodes both exited zero ([E24](evidence.md#e24):12–13,41–42; [E25](evidence.md#e25)). These are historical scheduler outcomes, not new tests or proof of artifact/physics validity. Raw logs and infrastructure addresses are not included.

| ID / priority | Confirmed behavior | Required improvement/test |
|---|---|---|
| C01 / high | EXIT handlers capture the prior status, disable error exits, write `runner_exit_code` **before** copying artifacts, and return the prior status ([E15](evidence.md#e15):36–64; [E16](evidence.md#e16):19–32). Copy errors therefore need not make a successful body fail. | Inject copy/disk failures with a stubbed runner. Publish an atomic completion manifest only after every required artifact is copied and verified; return nonzero on publication failure. |
| C02 / high | Pilot staging tests that a checksum report exists but does not verify the archive against it ([E17](evidence.md#e17):33–45). The LHE runner checks archive readability, then extracts it without a checksum comparison ([E15](evidence.md#e15):26–28,129–140). | Reject changed archive bytes despite an existing checksum sidecar. Verify immutable input identity before extraction. This finding concerns the original Delta441 pilot path. |
| C03 / medium | Staging fetches files from mutable `dev/wjets-recovery`, writing directly to destination paths ([E17](evidence.md#e17):6–23). | Pin one commit and a file manifest; download to temporary paths and publish a complete verified bundle. Test interrupted/mixed-revision downloads. |
| C04 / high | Results use fixed directories; any existing directory causes refusal. The DAG explicitly has zero retries ([E15](evidence.md#e15):22–25; [E16](evidence.md#e16):13; [E20](evidence.md#e20):6–7). Output-directory creation precedes completion. | Test eviction, termination and interrupted publication. Define attempt identities and a recovery path that distinguishes complete, failed and partial outputs; avoid blind regeneration of expensive stages. |
| C05 / medium | Submit files reserve resources and suppress automatic artifact transfer; runners perform manual shared-storage copying ([E18](evidence.md#e18):10–14; [E19](evidence.md#e19):9–13). | Validate resource use and durable artifact publication separately. CPU reservation and configuration markers alone do not measure useful parallel speedup. |

Useful existing safeguards: worker scratch checks, refusal to overwrite prior results, separate LHE/shower stages, upstream identity/status checks, and link preflight ([E15](evidence.md#e15):11–33,149–178; [E16](evidence.md#e16):35–70). Preserve them while adding failure tests. No live queue queries, submissions or retries were performed.
